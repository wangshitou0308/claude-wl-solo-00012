# 花样续针定位（stitch-locator）

面向钩针 / 棒针爱好者的断点续织定位工具。因停织数日、计数器误触或纸质记号脱落而忘记当前行时，通过现场观察（针数、朝向、线色、可辨特征）在花样循环中找回续针位置。全部运算在浏览器完成，数据存于本机 IndexedDB。

## 启动

```bash
npm install
npm run dev
```

浏览器打开终端提示的地址（默认 http://localhost:5173）。

## 功能流程

1. **花样循环**：逐行录入一个完整循环——正/反面、行末针数（加减针自动推算）、线色、扭花/镂空/引返等关键动作、行末标记；可填写织片总针数与重复单元，用于对称袖片/前后片影响推算。
2. **续针定位**：录入针上总数、织物朝向、当前线色、最近可辨特征及把握程度。应用保留全部相容行位，不凭单一特征猜测：
   - 唯一解时直接显示下一行动作；
   - 多解时并列候选，并推荐信息增益最大的观察项，列出每个答案对应的剩余行位；
   - 无解时列出每个行位被排除的原因。
3. **断点恢复**：确认位置后，针对漏针/多织可从最近八行模拟三条路径——拆回、补针/收针、继续织并在下一行调整，并标明对称织片受影响的重复单元。
4. **打印卡**：确认续针点时冻结观察与花样版本，生成只含接下来六行（行号 + 关键动作）的打印卡。

## 规则说明

- 花样每次改动版本号 +1，未确认的旧定位立即失效；已确认的打印卡保留冻结版本并提示版本差异。
- 把握程度为「有把握」时，可辨特征作为硬条件；否则只做吻合度打分，不会误删候选。
- 所有录入均可逐步撤销（页面顶部「撤销」按钮）。
- 刷新页面后自动恢复未确认的候选与现场观察。
